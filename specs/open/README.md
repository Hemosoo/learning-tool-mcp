# Open specs

Nothing is open. Both 0.7.0 feature specs shipped and moved to
`specs/done/`.

The remaining ideas live in `rebuild/future/deferred-roadmap.md`: semantic
chunking, packaging/CI/LICENSE, a widget confidence display, mind maps,
knowledge graphs, and multi-user. They are direction, not design — each needs
its own spec here before it is built.

That file also records one thing that was **removed, not deferred**:
server-side LLM generation. The host-generates/server-persists split is the
defining architectural decision; see `rebuild/01`.
